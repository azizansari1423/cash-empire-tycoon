# Roblox Tycoon — Game Design Document

## Concept
**Name (working title):** Cash Empire Tycoon  
**Genre:** Tycoon / Idle  
**Target audience:** Ages 8–16  
**Core loop:** Buy droppers → earn money → buy upgrades → unlock new areas → repeat

---

## Core Mechanics

### 1. Dropper System
- Players place "droppers" that produce items (coins, gems, crates)
- Items fall onto a conveyor belt → reach a collector → convert to cash
- Each dropper has a cost, production rate, and item value

### 2. Upgrade System
- Speed upgrades (faster belt)
- Value multipliers (items worth more)
- Auto-collect (no need to touch collector)
- Area unlocks (expand your tycoon plot)

### 3. Prestige System
- Reset your tycoon for a permanent multiplier
- Encourages repeat playthroughs and long retention

## Map Layout
- Central hub with 4–8 player plots
- Each plot: 50x50 studs
- Shared leaderboard visible to all
- VIP area for gamepass holders
